# We Got Cha Bistro - Davao City
Mobile-first web presence for We Got Cha Bistro.

## Tech Stack
- HTML5 / CSS3 (Terracotta & Moss Palette)
- Vanilla JavaScript (Dynamic Menu Loading)
- AEO-Optimized via llms.txt

## Deployment
Host on GitHub Pages, Vercel, or Netlify for best performance in the PH region.
