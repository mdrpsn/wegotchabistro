# We Got Cha Bistro website

Static one-page site for We Got Cha Bistro, Davao City. Plain HTML and CSS, no JavaScript, no build step.

## Files
- index.html: page content and Restaurant structured data
- style.css: styles
- favicon.svg, robots.txt, sitemap.xml, llms.txt

## Staging vs launch
While staged on GitHub Pages, index.html carries `<meta name="robots" content="noindex">` and a "Draft for review" banner. Remove both before pointing wegotchabistro.com here.

## Content sources
Menu items and branch links come from the foodpanda listing (We Got Cha - Main). Prices are not shown on the site because they change; the site links to foodpanda instead.
